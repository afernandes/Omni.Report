# Correção F13 — altura do canvas em papel contínuo

O F13 da auditoria de 05/09/2026 foi tratado no canvas direto dos backends PDF, Skia raster e GDI raster. O conteúdo desenhado abaixo de 80 mm passa a integrar a página Thermal80. O PDF deixa de usar o retângulo de gravação como altura física.

## Implementação

- `SkiaPdfRenderingContext` grava operações em `SKPicture` e cria a página PDF em `EndPage`, a partir dos limites das operações, recortes e margem inferior.
- `SkiaRenderingContext` segue a mesma gravação e só aloca o bitmap ao terminar a página, depois de verificar seu orçamento de pixels.
- O GDI independente grava em EMF+ e materializa o bitmap final em `EndPage`. Fontes gravadas usam tamanho explícito em pixels para respeitar o DPI solicitado, inclusive quando ele difere do dispositivo usado para gravar o metafile.
- Glifos, decoração de texto, espessura de traços, curvas, imagens e recortes participam da medida. O callback de caminho é executado uma única vez. O GDI mede o traço expandido, evitando a expansão excessiva de `GetBounds(pen)` pelo limite de junção.
- O PDF composto a partir do raster converte pixels em pontos usando o DPI do contexto. As assinaturas públicas anteriores permanecem disponíveis; as opções usam novas sobrecargas.
- Recursos temporários são liberados ao finalizar, rejeitar a alocação ou descartar a página. Uma rejeição de orçamento em `EndPage` permite começar outra página no mesmo contexto.

A altura usa o maior limite inferior visível, acrescido da margem inferior. Páginas vazias reservam margem superior, um pixel/ponto e margem inferior. Há uma folga conservadora de uma unidade do dispositivo em formas/texto para antialiasing e hinting. Recortes arredondados são considerados por seu envelope retangular: podem deixar espaço branco adicional; não se promete o menor retângulo de tinta possível. Coordenadas são absolutas, sem reaplicar a margem superior ao desenho.

## Limites e uso

`ContinuousPageOptions` configura por página:

| Opção | Padrão | Verificação |
|---|---:|---|
| `MaxHeight` | 10.000 mm | Altura incluindo a margem inferior; rejeita operações visíveis além do limite |
| `MaxRasterPixels` | 16.000.000 | Largura × altura antes de alocar o bitmap contínuo |
| `MaxOperations` | 100.000 | Chamadas de desenho e abertura de recorte durante a gravação |

```csharp
var limits = new ContinuousPageOptions
{
    MaxHeight = Unit.FromMm(2_000),
    MaxRasterPixels = 8_000_000,
    MaxOperations = 20_000,
};

using var raster = new SkiaRenderingContext(limits, dpi: 203);
using var gdi = new GdiRenderingContext(dpi: 203, continuousOptions: limits);
using var stream = new MemoryStream();
using var pdf = new SkiaPdfRenderingContext(stream, metadata: null,
    leaveOpen: true, continuousOptions: limits);
```

Esses limites não são um orçamento global de memória: imagens decodificadas, complexidade interna de um caminho, texto de uma chamada, páginas já retidas e concorrência do host continuam consumindo memória. Os contextos não são compartilháveis entre execuções simultâneas. Papel contínuo exige orientação retrato, largura positiva e margens verticais não negativas. Uma superfície GDI emprestada continua com o tamanho definido pelo host/driver; a biblioteca não redimensiona hardware ou superfícies externas.

## Reprodução e medidas atuais

O harness desenha texto em 90 mm, retângulo e imagem de 100 a 110 mm, com margem inferior de 5 mm. O texto permanece selecionável no PDF vetorial.

| Saída | Medida atual |
|---|---:|
| Skia PNG a 96 DPI | 303 × 436 pixels |
| GDI PNG a 96 DPI | 303 × 436 pixels |
| Skia PNG a 203 DPI | 640 × 921 pixels |
| GDI PNG a 203 DPI | 640 × 921 pixels |
| PDF vetorial | 227 × 327 pontos |
| PDF do raster a 96/203 DPI | 227 × 327 pontos |

O backend PDF desta execução arredonda o MediaBox a pontos inteiros; os testes permitem até meio ponto nessa representação. A dimensão histórica de 1.000.000 pontos pertence à auditoria original e não é uma medida da versão corrigida.

PdfPig verificou dimensões e texto selecionável. PyMuPDF decodificou os três PDFs e confirmou tinta no retângulo/imagem em 105 mm e branco na margem em 114 mm. A comparação GDI contínuo versus finito registrou diferenças de antialiasing/reprodução: 326 pixels a 96 DPI e 1.817 a 203 DPI; não se afirma igualdade pixel a pixel. Os limites dos glifos diferem no máximo dois pixels nos testes de DPI.

Uma imagem inicial de 1 × 1 pixel produziu cinza ao ser ampliada pelo GDI. O harness confirmou o mesmo resultado no caminho finito (R=133 a 96 DPI e R=136 a 203 DPI), decorrente da amostragem nas bordas. A regressão usa 8 × 8 pixels para verificar uma região interna opaca, sem alterar a interpolação do produto.
